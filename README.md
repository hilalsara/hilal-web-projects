# Hilal · Web Automation Portfolio

Dört adet bağımsız, dinamik HTML/CSS/JavaScript web uygulaması.

| Uygulama | Özellikler |
| --- | --- |
| [TalepFlow](talepflow/) | IT destek talepleri, durum yönetimi, filtreleme, CSV |
| [StokPilot](stokpilot/) | Envanter, SKU, kritik stok, hareket kaydı, CSV |
| [RandevuBoard](randevuboard/) | Randevu planlama, saat çakışma kontrolü, CSV |
| [WordLoop](wordloop/) | İngilizce kelime, eski kelime sınavı, dünün kartları, aralıklı tekrar |

## Çalıştırma
Kök dizindeki \`index.html\` sayfasını veya her alt klasörün \`index.html\` dosyasını tarayıcıda açın. Alternatif: \`python -m http.server 8000\` komutuyla yerel sunucu başlatın. Çevrimiçi yayın için GitHub Pages kullanılabilir.

**Önemli:** Bunlar tek kullanıcılı frontend demolarıdır; gerçek veritabanı ve kullanıcı giriş sistemi yoktur. Veriler sadece kullanılan tarayıcının \`localStorage\` alanındadır. Gerçek müşteri ve şirket bilgileri girmeyin. WordLoop'un tarayıcı içi ilerlemesi ChatGPT hatırlatmalarıyla otomatik senkronize değildir. ATHENA gerçek müşteri projesi bu public repoda yer almaz.
