# WordLoop

Türkçe İngilizce kelime öğrenme web prototipi. 95 kelimelik başlangıç bankası, Türkiye saatiyle günde beş oturum, önceki kelime sınavı, dünkü tekrar kartları ve 1/3/7/14/30 gün aralıklı tekrar. Veriler localStorage'da saklanır; ChatGPT hatırlatma otomasyonuyla çift yönlü senkronizasyon veya tarayıcı kapalıyken bildirim yoktur.

index.html dosyasını açarak kullanılabilir.
